# GHCN Climate Data Analysis

Large-scale climate data analysis using Apache Spark and PySpark.

## Technologies

- Apache Spark
- PySpark
- Microsoft Azure
- Azure Blob Storage
- Pandas
- Matplotlib
- Plotly
- Parquet

## Project Overview

This project analyses the Global Historical Climatology Network (GHCN) dataset using Apache Spark and PySpark.

The analysis involved processing more than 3.1 billion weather observations from over 100,000 weather stations across approximately 200 countries.

The project included data cleaning, schema definition, large-scale joins, data aggregation, geospatial analysis, time-series analysis and climate data visualisation.

## Key Work

- Processed large-scale climate data using PySpark.
- Integrated station, country, state and inventory datasets.
- Used efficient Spark joins and transformations for large datasets.
- Stored processed datasets in Parquet format.
- Analysed temperature and precipitation patterns.
- Investigated missing values, quality flags and outliers.
- Analysed long-term temperature trends across New Zealand weather stations.
- Created global precipitation visualisations and choropleth maps.
